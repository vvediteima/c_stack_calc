# c_stack_calc

Небольшой учебный калькулятор арифметических выражений на C.

Проект читает выражение из стандартного ввода, преобразует его во внутреннее стековое представление и вычисляет результат. Если во входной строке встречаются переменные, программа попросит ввести их значения отдельно.

## Поддерживаемый синтаксис

- числа и переменные
- круглые скобки
- операции `+`, `-`, `*`, `/`, `^`

## Сборка

```bash
gcc main.c -lm -o c_stack_calc
```

## Запуск

```bash
./c_stack_calc
```

После запуска введите выражение одной строкой.

## Назначение

Это учебный репозиторий для практики со строковым разбором выражений, пользовательскими стеками и базовой арифметикой в C.
